# Absurd Micro-Startup Pitch-Off

Entry for the make.fun bounty "Absurd Micro-Startup Pitch-Off". The program
writes a single one-sentence pitch to `/output/entry.txt`: a micro-startup
selling pre-written "sorry, the deploy failed" apology emails to AI coding
agents for $0.10 each, with a bulk discount for repeat offenders — an
absurdly narrow niche with a real buyer and a real price.
